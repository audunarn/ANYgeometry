# Explicit preparation epochs

`clone_prepared_geometry(model, new_preparation_epoch=True)` creates a detached logical model with a fresh UUID and the same revision, live geometry, raw native support coefficients, structural payload, and historical replacements. It does not copy prior preparation or admission receipts. The source remains unchanged. The default call retains its existing behavior.

The fresh clone carries an owner-issued, exact-object first-preparation permit. Authoring before its first successful apply is intentionally part of the new baseline. Build a new plan after authoring, then use the normal committed `plan_intersections` / `apply_intersections` path. Old-model and stale plans refuse. The first epoch apply inside a caller-owned journal refuses explicitly. Cancellation or publication failure preserves topology, receipts, and the permit for retry. Existing observer-hook exceptions retain the model's catch-and-report contract.

The first preparation captures only current live faces, edges, and attachment identities. Historical lineage remains intact, but cannot select an epoch attachment source. A transient candidate draft follows actual face/edge remappers; a sealed current-to-source map distinguishes distinct original relations even when their old history names other live originals. Actual owner-created attachments are tracked separately, and every active attachment must belong to exactly one of these inventories. Unknown, missing, conflicting, forged, and orphan map entries refuse. Owner-created provenance does not itself prove spatial truth: existing complete incidence and native geometry checks still apply.

Successful face and edge receipt publication consumes the permit. Later authoring retains the ordinary stale-provenance refusal; an explicit new epoch is required again. Permits and maps are local evidence, excluded from document schemas. Ordinary clones and document loads cannot inherit a first-preparation permit. Qualified prepared clones can copy authenticated current evidence through the existing owner path.

Native material and reference scope claims retain their existing supported-family restrictions. Epoch rebasing grants no runtime/libm roundoff proof, opaque or external reference interpretation, composed coordinate error from separate tolerances, or mesh admission.

Cached idempotent application also checks the receipt, revision, document, epoch source/creation seal and actual raw native supports after any cancellation callback. Unsupported native scope refuses. A callback that authors unrelated geometry keeps its authoring; the cached application refuses the changed binding.

Epoch plans also carry owner-issued transient planning-time raw-support evidence. Capture precedes planning callbacks; a final callback-free guard checks native coefficients, UUID, revision and document before issuing the plan. Apply compares those coefficients before candidate capture. Restoring the original raw coefficients permits reuse of the otherwise unchanged plan. The registry holds only weak plan references, is not serialized, and binds the plan identity and logical inputs rather than a model object pointer, permitting compatible qualified clones. Default plans retain their existing public behavior.
