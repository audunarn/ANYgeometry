# Prepared vertex identity ancestry

`query_prepared_vertex_preimages(model, *, expected_revision=None,
cancellation_check=None)` returns a frozen `PreparedVertexPreimages` bound to
the complete original/current `PreparedModelScope`. Authenticate it using
`validate_prepared_vertex_preimages_binding(model, receipt)` before consuming
the mapping and after caller-controlled work.

`authored_resolutions` records every vertex active in the prospective original
document: original ID, owner resolution status and current vertex IDs.
`current_to_authored` records every current vertex, including isolated vertices,
with all its original active vertex ancestors. A weld can have several ancestors.
`authored_positions` and `current_positions` retain immutable document positions.
No matching by position is performed. The ID tuples are deterministic sets;
they do not describe edge traversal, offsets or source parameter order.

`without_authored_vertex` means precisely **no original active vertex ancestor**.
A station generated by splitting an original edge can still carry an original
edge, member, attachment or feature reference. This field must not be used as
blanket generated-only provenance or proof that all source references are absent.
Deleted original vertices remain explicit with no surviving vertex descendants.

This query proves identity ancestry and snapshot freshness. It does not prove
coordinate equivalence, mesh membership, original/current parameter remapping,
load/support preservation or permission to publish a mesh. Consumers retain
their complete reference inventory and reject unsupported association classes.
Ordered edge chains require the separate owner edge-preimage/station contracts.
An ordinary cloned or reloaded model without local preparation evidence refuses.
