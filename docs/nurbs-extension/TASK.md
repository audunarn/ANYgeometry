### Hierarchical residual bound (UNRUN)

Derived and verified identity (own proof, not adopted blindly): for a bidegree-(2,2) residual R on [0,1]^2 let B be the bilinear interpolant of the corner values and `a0 = 4R(.5,0)-2R(0,0)-2R(1,0)`, `a1 = 4R(.5,1)-2R(0,1)-2R(1,1)`, `b0 = 4R(0,.5)-2R(0,0)-2R(0,1)`, `b1 = 4R(1,.5)-2R(1,0)-2R(1,1)`. On y=0, R-B is a quadratic in x vanishing at 0 and 1, hence `x(1-x)` times its value-at-1/2 scale, which gives a0 (likewise a1, b0, b1 on the other edges). `E = R - B - x(1-x)[a0(1-y)+a1 y] - y(1-y)[b0(1-x)+b1 x]` therefore vanishes on all four edges and has bidegree <= (2,2), so `E = c x(1-x) y(1-y)` with `c` constant; the centre gives `c = 16R(.5,.5) - 4(sum of corner values) - 2(a0+a1+b0+b1)` (matches root's formula).
