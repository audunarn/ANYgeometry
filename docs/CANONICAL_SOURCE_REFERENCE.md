The source-cell and prepared-boundary pipeline resolves one canonical owner
through source_cell_complex._support_owner. Installed sweep recipes retain their
existing chart_model route. Canonical raw Coons sweeps use the fresh public
source_sweep_chart_model read view; unsupported faces keep the original model.
Literal Plane and NurbsSurface ownership is unchanged.

Sampling references build their vertex identities from genuine owner-declared
CurveOnSurface boundaries. Occurrence UV enclosure reuses the same operation-local
owner. Local field footprints use the same resolver. No approximate world point
is used to reconstruct a missing vertex identity, and no chart is installed.

The original world curve and stored endpoint positions remain the sampling
targets. World-affine recognition only changes the station proposal fraction;
_cell_reference_world_chord still bounds its midpoint residual plus integrated
derivative residual against those actual endpoints. A raw connector can therefore
be affine on the ideal support and still have a strictly nonzero world transport
bound. Existing offset, tolerance, allocation, source/callback, one-sided and
final receipt guards remain in force.
